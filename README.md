# Solar System VR
Solar System VR is an interactive virtual reality visualization of the solar system.

## Features
- Immersive VR solar system experience
- Interactive exploration of planets
- Educational visualization of planetary scale and layout

## Requirements
- Unity (version 6000.3.18f1)
- Meta Quest 3
